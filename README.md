# Palavra do Dia

Página simples que mostra um **versículo bíblico aleatório** a cada visita, com botão para trocar de versículo e outro para copiar o texto.

## Como funciona

- Busca um versículo aleatório (NVI) na API pública [A Bíblia Digital](https://www.abibliadigital.com.br/)
- Se a API estiver fora do ar, usa uma **lista reserva** de versículos guardada no próprio código, então a página nunca fica vazia
- O botão **Copiar** coloca o versículo e a referência na área de transferência

## Tecnologias

- HTML, CSS e JavaScript puro
- `fetch` para consumir a API

## Como abrir

Abra o `index.html` no navegador.
